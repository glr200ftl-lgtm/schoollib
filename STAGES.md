# Этапы проекта

## Готово

### Этап 1 — Каркас проекта, схема БД, демо-данные ✅
- Стек зафиксирован: Python 3.12 + Django 5.x + PostgreSQL 16 (dev — SQLite через `DATABASE_URL=sqlite`).
- Модели и миграции: `users`, `categories`, `books`, `ads` (поля по ТЗ п.6).
- Layout: шапка (логотип, меню Главная/Каталог/Обмен), футер (контакты школы).
- Seed: `python manage.py seed_demo` — 3 пользователя, 6 категорий, 12 книг
  с обложками-заглушками (Pillow), 3 объявления; идемпотентен.
- Заглушки страниц: `/`, `/catalog/`, `/exchange/` (200, общий layout).
- README.md с командами установки/запуска.
